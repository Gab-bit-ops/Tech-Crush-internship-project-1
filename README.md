# 🛒 Retail Store Sales Analysis
# 📌 Project Overview

This project focuses on the cleaning, validation, analysis, and visualization of a retail sales dataset using Microsoft Excel.
The objective was to transform a raw and potentially inconsistent retail dataset into a reliable dataset that could be used to generate meaningful business insights and support data-driven decision-making.
The project followed a structured analytics workflow:
Raw Data → Data Cleaning → Data Validation → Business Analysis → Visualization → Insights

# 🎯 Project Objectives
Clean and prepare the raw retail sales dataset for analysis.
Identify and remove duplicate records.
Validate the consistency and accuracy of the dataset.
Use the provided Master Sheets to verify customer, product, location, and branch information.
Identify and investigate null or inconsistent values.
Develop business-focused questions from the cleaned dataset.
Analyze sales performance using PivotTables and PivotCharts.
Build an interactive retail sales dashboard using Excel 
Generate insights that can support business and sales decisions.

# 🧹 Data Cleaning & Preparation
1. Duplicate Record Removal
During the initial inspection of the dataset, duplicate records were identified.
Since there was no reliable reference available to determine which of the duplicated records represented the correct transaction, the duplicate records were removed to prevent them from distorting the analysis.
This helped ensure that:
Sales were not overstated.
Transaction counts were not inflated.
Product quantities were not duplicated.
Business insights were based on unique records.
2. Master Sheet Validation
The provided Master Sheets were used as reference tables during the data-cleaning process.
Rather than relying solely on the transactional dataset, the master data was used to verify whether information in the sales records was accurate and consistent. The Master Sheets were also used to validate relevant product and customer information and ensure that the transactional data corresponded with the available reference data. This step significantly improved the reliability of the final dataset.
3. Null Value & Accuracy Checks
The cleaned dataset was further examined for:
Missing values
Invalid entries
Inconsistent categorical values
Incorrect relationships between fields
Data entries that did not correspond with the Master Sheets.

# 📊 Business Analysis
After completing the data-cleaning and validation process, the cleaned dataset was used to answer practical business questions.
Some of the key questions explored included:
Sales Performance
What is the total revenue generated?
How many orders were recorded?
How many units were sold?
What is the Average Order Value?
How does sales revenue change over time?
Product & Category Performance
Which product categories generate the highest revenue?
Which products are the top revenue generators?
Which products contribute significantly to overall sales?
Branch Performance
Which branches generate the highest sales?
How does sales performance differ across locations?
Payment Analysis
Which payment methods are most commonly used?
What proportion of sales comes from each payment method?
These questions helped move the project beyond basic data visualization toward business-oriented analysis.
